# Decisions

## ADR-001: Minimal Markdown profile

Accepted 2026-09-29. Use native headings and a technology table without external assets, badges, or GIFs for a sober and maintainable profile.
Project names are provided, but project descriptions and public URLs are not; use neutral descriptions without inventing details or exposing private repository content.
Omit license and .gitignore as explicitly requested. Keep required workspace tracking documents concise and in English.
